# bioRxiv Submission Plan

## Recommended Server

bioRxiv

## Recommended Category

Bioinformatics

Secondary fit: Systems Biology

## Submission Framing

This manuscript should be submitted as a computational biology benchmark of public human cardiac omics datasets. It should avoid claims about patient diagnosis, prognosis, or treatment efficacy.

## Required Before Submission

- Final manuscript PDF
- Figures and figure captions
- Supplementary tables
- Code repository URL
- Data availability statement
- Competing interests statement
- Author contribution statement
- Funding statement, if applicable
- Ethics statement noting reuse of public de-identified datasets

## Data Availability Draft

All analyses use publicly available datasets. Dataset accessions, source URLs, and processed data locations are listed in Supplementary Table 1. No new human participant data were generated for this study.

## Code Availability Draft

All code required to reproduce the analyses and figures will be made available in a public GitHub repository at the time of preprint posting.

## Competing Interests Draft

The author declares no competing interests.

## Ethics Draft

This study reanalyzes publicly available de-identified transcriptomic datasets. No new human participant recruitment, sample collection, or intervention was performed.

## Outreach After Posting

After posting the preprint, send concise emails to:

- cardiac single-cell atlas researchers
- computational cell-cell communication method developers
- cardiovascular genomics researchers
- spatial transcriptomics researchers

Goal: request technical feedback, not endorsement.
